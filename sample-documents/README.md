# Sample documents

Demo policy files for local RAG testing.

1. Run `make seed` (or sign in as an existing admin).
2. Upload any file below via **Admin → Upload**.
3. Ask the suggested question in **Assistant**.

| File | Department | Suggested question |
|------|------------|--------------------|
| `hr-pto-policy.txt` | HR | How many PTO days do employees receive? |
| `it-acceptable-use.txt` | IT | Are personal cloud drives allowed? |
| `finance-expense-policy.txt` | Finance | What is the meal expense limit? |

These are fictional internal policies for portfolio demos only. curl upload examples:
[docs/api-examples.md](../docs/api-examples.md).
